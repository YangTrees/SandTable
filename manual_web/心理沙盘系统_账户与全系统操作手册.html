文档说明

先确认手册的适用范围、入口边界和术语，再开始操作。

1.1 目的与适用范围1.2 版本与术语

1.1目的与适用范围

本手册用于指导学校心理服务团队使用心理沙盘发展性评估系统。内容覆盖系统入口、账号登录、用户与角色管理、学生测评组织实施、报告审核、报告查看和家长/学生分享。

本手册以2026年11月22日的当前部署为基准，主要供超级管理员、心理咨询师、班主任和系统运维人员使用；学生可按附录D的快速指引完成测评。系统界面、字段或权限如有调整，以实际页面为准。

使用前先确认

本手册中的地址均以当前本机部署 http://127.0.0.1:8011 为例。若系统部署到其他服务器，请只替换地址中的主机和端口，页面路径保持不变。

系统分为两条独立入口：后台 /admin 只面向教职员工；工作台 /workbench 只面向受测学生。教师、咨询师、超管不能进入工作台，学生也不能进入后台。

学生账号只能由超级管理员在后台“用户与角色”中创建并设置密码。学生忘记密码时，联系心理老师或管理员重置。

后台与工作台不是同一套入口：后台使用教职员工账号，工作台使用学生账号，两个登录接口会互相拒绝对方角色。为避免心理数据泄露，应只在受控电脑、受控网络和授权人员范围内使用，不要把内部页面地址发到公开群组。

3.1首次登录准备

首次使用后台前，先向超级管理员确认账号是否已建立、角色是否正确、是否已设置初始密码。学生首次测评前，由学校统一发放学生账号和密码，学生不需要自己注册。系统不会把密码通过页面展示给他人，初始密码应由管理员当面或通过受控方式交付。

建议使用最新版 Chrome 或 Edge 浏览器，并保持浏览器缩放为100%。如果页面显示旧版内容，先按 Ctrl+F5 强制刷新，再重新登录。3D沙盘需要浏览器支持 WebGL，显卡加速应保持开启。

3.2后台登录步骤

表5　后台登录操作步骤

步骤操作说明
1打开教职员工控制台在浏览器地址栏输入 http://127.0.0.1:8011/admin。
2输入登录账号账号由超级管理员创建，例如 lin.zhiyuan；不区分大小写，系统会统一转为小写。
3输入登录密码点击密码框右侧的眼睛图标可以显示或隐藏密码；输入完成后按 Enter 或点击“登录控制台”。

后台登录接口只接受教职员工账号。使用学生账号访问后台会被拒绝，并提示学生应从沙盘工作台进入。学生登录步骤见6.1节。

密码与账号规则

密码长度为8—128位，至少包含字母和数字；建议再加入符号，但系统只强制字母和数字。

账号为3—32位小写字母、数字、点、下划线或短横线，且必须以字母或数字开头。

连续5次密码错误会锁定账号15分钟；锁定期间即使密码正确也不能登录。

3.3登录后的工作概览

工作概览是默认首页，展示评估报告总数、待审核数量、L2及以上重点关护数量、可访问分享链接数量，以及审核队列和预警等级分布。咨询师每天开始工作时，先看“待审核”和“重点关护”，再进入审核队列。

页面顶部“已同步”表示最近一次数据刷新时间。需要立即获取最新数据时，可点击浏览器刷新或进入报告审核页点击“刷新队列”。

3.5登录状态恢复与失效

登录状态保存在当前浏览器标签页的会话中，有效期12小时。同一标签页刷新页面可以自动恢复登录；关闭标签页后，通常需要重新输入账号和密码。

如果页面提示“登录状态已失效”，说明会话已过期、被管理员撤销，或账号被停用。此时系统会清空本地登录状态并重新显示登录页，重新登录即可；如果仍无法登录，按第9章的登录类问题排查。

退出后如果再次打开同一地址仍显示已登录，先刷新页面确认；仍有异常时关闭标签页后重新打开登录页。

4.1工作概览与指标

工作概览中的四个指标分别对应：全部评估报告、待审核报告、L2及以上重点关护报告、当前可访问的分享链接。审核队列按风险线索和时间排序，便于先处理风险较高的报告。

“预警等级分布”按每份报告的最高等级统计；“需要重点关护”列出L2及以上报告。指标只用于工作排序，不能替代咨询师的专业判断。

4.3修订、退回与通过

“修订 AI 正文”用于咨询师对报告正文做必要校正。打开后按章节编辑，填写审核意见，先点“保存草稿”；草稿保存后报告状态会进入“待修订”，审核通过时系统将草稿合并为正式报告。

“退回修订”适合发现事实、表述或建议需要补充的情况。退回后应在审核意见中写清楚需要修改的章节和问题，避免只写“请修改”。

“审核通过”表示报告可以用于分享。通过前应确认：受测者信息无误、代表沙具选择正确、风险章节已核对、家长版不会暴露咨询师内部判断。

谨慎使用“用大模型重分析”

该按钮会调用已配置的多模态模型重新分析记录，并覆盖当前报告内容。使用前应确认原报告可重新生成，且当前修订草稿不会被需要保留的内容覆盖。

日常审核优先使用正文修订和审核意见，不建议把“重分析”当作普通刷新按钮。

4.4生成分享二维码与复制链接

审核通过后，点击审核页右下角“生成二维码”。系统弹出“报告分享二维码”，可让家长或学生扫码，也可点击“复制分享链接”发送给家长。分享页自动隐藏风险研判章节和咨询师内部字段。

二维码中的地址由服务器配置决定。如果二维码指向 127.0.0.1 或 8000 等本机地址，手机将无法打开；此时应联系系统管理员，把对家长开放的地址配置为手机可访问的域名或局域网地址。

4.5数据看板

数据看板汇总报告数量、L2及以上占比、中心区域沙具数量、首要训练需求、风险分布、模块分布和区域热力图。它用于查看群体趋势和安排训练资源，不用于给单个学生贴标签。

看板数据来自已完成报告。报告数量或分布与预期不一致时，先确认筛选范围和报告状态，再判断是否为数据问题。

6.3选择与摆放沙具

右侧“沙具抽屉”共500件沙具，按人物、建筑、自然、动物、交通、学习、体验、饮食等分类。可以点击分类筛选，也可以在搜索框按名称、子类或意象检索。

点击沙具卡片可将沙具加入沙盘，或直接把卡片拖入沙盘指定位置。选中沙具后，中部下方出现微调条：逆时针/顺时针旋转15°、水平镜像、缩小/放大、移除。

学生按自己的节奏选择和摆放，陪同人员只做设备和安全方面的必要协助，不替学生决定沙具位置或解释象征意义。作品本身比“摆得整齐”更重要。

顶部“拍照 n/6”可保存制作过程快照，最多6张；快照会随作品一并提交，帮助心理老师了解制作过程，不替代最终沙盘图。

安全规范与日常检查

账号、密码、心理数据和日常检查的底线要求。

10.1 账号与密码10.2 心理数据与分享10.3 日常检查清单

10.1账号与密码

账号实行一人一号。超级管理员账号只保留必要数量，不与其他角色共用；学生账号只发给学生本人，教师和咨询师不得借用学生账号进入工作台。离职、调岗、长期请假或发现异常登录时，先停用账号，再按流程处理。

密码只在本人和管理员之间当面或通过受控方式传递，不得写在纸质公告、群公告、共享表格或聊天记录中。发现密码可能泄露时，立即重置并停用旧会话。

使用公共电脑或借用设备时，操作结束必须退出登录：后台点右上角“退出”，学生工作台点顶部“退出”。不要让浏览器保存密码，不要勾选“记住密码”。

10.2心理数据与分享

沙盘作品、学生自述、文字补充和报告都属于敏感心理数据。只能在授权工作场景中使用，不得公开发布、不得用于与评估无关的排名、分班或评优。

学生提交后，作品与文字进入后台，由心理老师查看和审核。学生端不展示风险判断或临床结论；分享前确认对象是家长本人或受测学生本人，不要把分享链接转发给无关人员。

需要截图或导出PDF用于督导、培训时，先去除姓名、学号、班级等可识别信息，并确认接收方的保密义务。

APPENDIX D / INTERNAL MANUAL

学生测评快速指引（可单独打印）

可单独打印给学生：登录、完成、提交、退出四步。

D.1 开始前D.2 四步完成测评D.3 离开前

这份指引给学生本人看。你只需要完成一次沙盘，并在结束时提交给学校心理老师。

D.1开始前

使用学校发给你的学生账号和密码登录测评入口。账号只能本人使用，不要借给同学。登录后先确认姓名、学号和班级是否正确；如果有误，告诉心理老师，不需要自己修改。

D.2四步完成测评

表32　学生测评四步

步骤你要做什么看到什么
1打开测评入口，输入学生账号和密码，点击“开始测评”进入“学生心理沙盘测评”
2按自己的想法摆放沙具、堆沙、挖水；想调整就撤销或重做中部是3D沙盘，右侧是沙具抽屉
3点击“完成并提交”，选一件最能代表此刻的你、最像你的沙具进入“SUBMIT WORK / 作品提交”
4写一段沙盘描述（不少于10字），勾选知情同意，点击“提交本次作品”看到“作品已提交”和提交编号
提交后你会看到什么

你会看到提交时间、短编号、作品图，以及沙具数、占用区域、中心区域沙具三项统计。

工作台不会向你展示风险判断或临床结论。需要进一步沟通时，心理老师会另行联系你。

如果提交失败，先保存高清作品图，再告诉心理老师，不要反复刷新页面。

D.3离开前

如果使用的是学校公共电脑，提交完成后点击顶部“退出”，确认回到登录页再离开。不要把自己的账号密码留在纸上、桌面上或聊天记录里。
